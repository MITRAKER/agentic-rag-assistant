# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome newcomers and their
questions, assume good intent, and critique code rather than people.
Harassment, insults and personal attacks aren't tolerated in issues, pull
requests, reviews or anywhere else the project is discussed.

## Reporting

If someone's behaviour concerns you, contact the maintainer privately, using
the contact details on [their GitHub profile](https://github.com/MITRAKER).
Reports are kept confidential. The maintainer may edit or remove comments,
lock conversations, or block people who don't follow this code of conduct.
